# ML Quiz

머신러닝 단답형·서술형 문제를 풀고 정답을 토글해서 확인하는 개인용 복습 페이지.

https://jangsuy.github.io/ml-quiz/

- 단답형과 서술형은 완전히 갈린다. `#short`, `#essay` 로 바로 열 수 있다.
- 각 유형 안에서 `topic` 단위로 섹션이 나뉜다. 섹션은 기본으로 접혀 있고, 헤더를 누르면 펼쳐진다.
- 카드의 👎 를 누르면 별로인 문제로 표시된다. 헤더의 `목록 복사`로 표시한 id를 뽑아 `questions.json`에서 지우면 된다.
- 입력한 답, 섹션 펼침 상태, 별로 표시는 모두 브라우저에 저장된다. 기기마다 따로 남는다.

## 문제 추가

`questions.json`에 항목을 넣고 push하면 1분 안에 반영된다.

```json
{
  "id": "q021",
  "type": "short",
  "topic": "평가지표",
  "tags": ["일반화"],
  "question": "문제 내용",
  "answer": "정답. 줄바꿈은 \\n, 문단은 \\n\\n."
}
```

| 필드 | 설명 |
|---|---|
| `id` | 겹치면 안 된다. 입력한 답을 저장하는 키라서 바꾸면 그 답이 사라진다 |
| `type` | `short` 또는 `essay` |
| `topic` | 섹션을 결정한다. 하나만 쓴다 |
| `tags` | 카드 배지로만 보인다. 빈 배열이면 생략된다 |
| `question` | 번호는 화면에서 자동으로 붙는다 |
| `answer` | `\n`이 실제 줄바꿈으로 보인다. 마크다운은 파싱하지 않는다 |

섹션 순서는 `questions.json`에서 그 `topic`이 처음 나온 순서를 따른다. 순서를 바꾸고 싶으면 항목 위치를 옮기면 된다.

## 수식

KaTeX를 쓴다. `$...$`는 문장 안에, `$$...$$`는 별도 줄에 렌더된다.

**JSON에서는 백슬래시를 두 번 써야 한다.**

```json
"answer": "그래디언트는 $(\\hat{y} - y)x$ 로 남는다."
```

`\frac`이 아니라 `\\frac`이다. 한 번만 쓰면 JSON 파싱이 깨진다.
